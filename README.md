# Fly.io

## 🚀 Шаг 1. Установить Fly.io CLI (командную утилиту)

Открой **PowerShell**  и вставь:

```bash
iwr https://fly.io/install.ps1 -useb | iex
```

Это установит Fly.io CLI на Windows.

👉 **Если появятся предупреждения об исполнении скриптов**, введи:

```bash
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

---

## 🔐 Шаг 2. Авторизоваться

После установки введи в том же окне:

```bash
fly auth login
```

Откроется браузер, где ты залогинишься через свой аккаунт Fly.io.

---

## ✅ Шаг 3. Проверить, что всё работает

Введи:

```bash
fly version
```

Ты должна увидеть номер версии, значит всё установилось корректно.

---

## 🔍 Шаг 4. Посмотреть список своих приложений

```bash
fly apps list
```

Если ты видишь своё приложение в списке — всё хорошо. Запомни его имя (например: `my-fly-app`).

---

## 📜 Шаг 5. Смотреть логи

```bash
fly logs -a my-fly-app
```

🔁 Логи будут "течь" в реальном времени — как консоль на сервере.

---

## 💡 Пример

Если твоё приложение называется `telegram-mini-app`, то:

```bash
fly logs -a telegram-mini-app
```

Отличный вопрос! Логи в Fly.io через CLI «текут» в реальном времени, и чтобы **остановить их**, достаточно просто **остановить выполнение команды в терминале**.

---

## ✅ Как остановить вывод логов:

### ⌨️ Нажми комбинацию клавиш:

```plaintext
Ctrl + C
```

### 📄 Сохранение логов Fly.io в файл:

```bash
fly logs -a my-app > logs.txt
```

📌 Это сохранит текущие логи в файл `logs.txt` в той же папке.

А чтобы «слушать» логи в реальном времени и писать их в файл:

```bash
fly logs -a my-app >> logs.txt
```

(`>>` — добавляет к файлу без перезаписи)
